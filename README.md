## 🛠 Tech Stack

- **Language:** Java 21
- **Framework:** Spring Boot
- **Web Layer:** Spring Web
- **Persistence:** Spring Data JPA
- **Database:** MySQL
- **Build Tool:** Apache Maven
- **Utilities:** Lombok, Spring Boot DevTools

## 🏗 Architecture

`Client → Controller → Service → Repository → MySQL`

A layered architecture approach for organizing web requests, business logic, data access, and persistence.

## 🚀 Getting Started

**Prerequisites:** Java 21+, MySQL, and Git.

```bash
git clone https://github.com/Rashmiranjan07/Spring-Web-App.git
cd Spring-Web-App
```

Configure your database credentials in `src/main/resources/application.properties`, then run:

**Windows**
```bash
mvnw.cmd spring-boot:run
```

**macOS / Linux**
```bash
./mvnw spring-boot:run
```
